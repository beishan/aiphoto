## 环境说明

主机现有模拟器在虚拟化时触发 `delay_halt_tpause` 内核异常。实际测试使用独立临时数据目录及 `-qemu -append clearcpuid=517` 启动 API 36 镜像，绕过 CPU 特性不兼容；没有把此参数写入应用或已有 AVD 配置。这属于本机测试环境问题，不是客户端运行所需设置。
